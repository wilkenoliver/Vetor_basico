# 📚 Vetor de Registros em C

Projeto desenvolvido para praticar **vetores, registros (`struct`) e estruturas de repetição em C**.

## 📝 Sobre o projeto

O programa permite cadastrar alunos e armazenar suas informações em um vetor de registros.

Cada aluno possui:

* Nome
* Idade
* Nota

## 💻 Conceitos utilizados

* `struct`
* Vetores
* `for`
* `scanf`
* `printf`
* Tipos `char`, `int` e `float`
* Acesso a registros através de índices

## ⚙️ Funcionamento

O programa cadastra **3 alunos** e depois exibe todos os alunos cadastrados.

Exemplo:

```text
Aluno 1
Nome: João
Idade: 20
Nota: 8.5

Aluno 2
Nome: Maria
Idade: 19
Nota: 9.0
```

## 🎯 Objetivo

Este projeto faz parte dos meus estudos de **programação em C**, com foco no aprendizado de estruturas de dados básicas e organização de informações.
